# Khizer Mahmud — portfolio

Personal site based on the open-source template [rajesh-portfolio](https://github.com/raxx21/rajesh-portfolio) (React, TypeScript, GSAP, Three.js).

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Customize from your résumé

See **`resume.md`** for which files to edit (About, Career, Work, Contact).

**GSAP Club / trial:** The upstream README notes trial-only plugins can block some hosting setups. See [GSAP installation docs](https://gsap.com/docs/v3/Installation/) if you deploy and hit licensing issues.
